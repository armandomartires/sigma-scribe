# Report a bug

Report bugs and ask for features at [github.com/armandomartires/sigma-scribe/issues](https://github.com/armandomartires/sigma-scribe/issues).

## What to include

- What you did, what you expected and what happened.
- The Σscribe version, from Settings → **Help & about** → App info.
- Your Kobo model.
- Whether it happens every time.
- The log file, if you can. Turn on Settings → **Logging**, repeat the problem, then copy `.adds/sigma-scribe/log/sigma-scribe.log` from the Kobo. See [The log file](the-log-file.md).

## Before you send the log

The log can contain file paths and Wi-Fi network names. It never has Wi-Fi passwords or IP addresses. Read it first all the same.

## Check the common fixes

Your problem may be in [Common problems](common-problems.md).

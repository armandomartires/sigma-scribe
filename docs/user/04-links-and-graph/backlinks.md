# Backlinks

A backlink is a note that links to this one with a `[[wiki link]]`.

## See them

1. Open the note and switch to Preview. See [Preview](../03-write-and-edit/preview.md).
2. Turn to the last page. After a rule, a **Backlinks** heading lists every note that links here.
3. Tap a name to open that note. Back returns you.

If no note links here, the section says "No other notes link here."

## On the Graph

In the Graph list each note shows its links: `→` for the notes it links to, and `←` for the notes that link to it. See [The Graph](the-graph.md).

## Good to know

- A link like `[[note#heading]]` counts as a link to `note`.
- Backlinks follow the links in the notes as they are now. When you rename or move a note, the links to it are updated.

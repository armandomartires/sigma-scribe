# Line mode and page layout

Settings → **Writing** holds the settings that shape the page.

## Line mode

Line mode fits the text to a set number of words per line.

1. Open Settings → **Writing**.
2. Under **Line length**, turn **Line** On.
3. Set **Words per line**, from 8 to 16. It starts at 12.

While Line is on, **Size** and **Margin** are tied: moving one moves the other, so the line keeps its words. **Words per line** is greyed while Line is off.

## Text

- **Type:** the typeface.
- **Size:** the text size, on a slider.
- **Leading:** the space between lines, from 1.2 to 2.0.
- **Margin:** room at the sides for a thumb.

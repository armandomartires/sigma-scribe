# Select, copy and paste

## With a touch

- Double-tap a word, or press and hold on it, to select it. A bar appears with **Cut**, **Copy**, **Paste** and **Select all**.
- After a long press, keep your finger down and move it to extend the selection word by word.
- Drag the handle at either end of the selection to change it. The other end stays where it is.
- **Cut** removes the selected text and keeps it. **Copy** keeps it and leaves the note alone. **Paste** puts the kept text at the caret, or in place of the selection.

With only a caret and no selection, the bar shows **Paste** and **Select all**.

## With a mouse

Drag from the note to select. Double-click a word to select it. See [Mouse and touchpad](../09-usb-keyboard-and-mouse/mouse-and-touchpad.md).

## With the keyboard

On the on-screen keyboard tap **Ctrl**, then a letter. On a USB keyboard hold Ctrl as usual.

| Keys | What it does |
|---|---|
| Ctrl+A | Select all |
| Ctrl+C | Copy |
| Ctrl+X | Cut |
| Ctrl+V | Paste |

Shift with an arrow key extends the selection; Ctrl with an arrow key moves by a word. More keys are in [Shortcuts](../09-usb-keyboard-and-mouse/shortcuts.md).

## Good to know

- Σscribe keeps what you copied inside the app. Nothing is shared with the Kobo's other apps.
- Paste does nothing while nothing has been copied.

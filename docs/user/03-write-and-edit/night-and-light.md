# Night and light

## Dark mode

Settings → **Display** → **Page** → **Dark mode** On shows the same page inverted: light text on dark. Off is the default. The screen flashes once when you switch, to clear the old page.

## Keyboard tone

Settings → **Keyboard & input** → **Keyboard tone** lets the keyboard differ from the page:

- **Theme** follows Dark mode (the default).
- **Light** is always paper colours.
- **Dark** is always night colours.

## Front light

On a Kobo with a front light, Settings → **Display** → **Light** has **Backlight**, a slider from Off to Full. **Warmth** sits under it on a Forma, from Cool to Warm.

The sun icon in the title bar opens a small menu with the same sliders, in the note or in Preview. Both places agree.

- Backlight is not saved: Σscribe leaves the light as you set it when it exits.
- Warmth is saved, and applied again when Σscribe starts.

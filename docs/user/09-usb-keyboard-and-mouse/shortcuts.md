# Shortcuts

These keys work on a USB keyboard once it is connected. See [Connect](connect.md). On the on-screen keyboard, tap **Ctrl** first, then the letter.

## Edit

| Keys | What it does |
|---|---|
| Ctrl+A | Select all |
| Ctrl+C | Copy |
| Ctrl+X | Cut |
| Ctrl+V | Paste |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+F | Open the Find bar |
| Tab | Insert spaces (4 by default), or a tab character if Settings → Tab key is set to Tab |
| Backspace, Delete | Delete before or after the caret |

More on these in [Select, copy and paste](../03-write-and-edit/select-copy-paste.md) and [Undo and redo](../03-write-and-edit/undo.md).

## Move

| Keys | What it does |
|---|---|
| Arrow keys | Move the caret |
| Ctrl+Left, Ctrl+Right | Move by a word |
| Home, End | Start or end of the line |
| Ctrl+Home, Ctrl+End | Start or end of the note |
| Page Up, Page Down | Move by a page |

Hold Shift with any of these to select as you move.

## Good to know

- Ctrl+Z is Z wherever the key sits on your layout, so the shortcuts keep their letters.
- Ctrl and Alt shortcuts that Σscribe does not use do nothing.
- In a right-to-left line, Left and Right swap. See [Right-to-left text](../08-keyboards-and-languages/right-to-left.md).
- Mouse and touchpad are in [Mouse and touchpad](mouse-and-touchpad.md).

# Export

Notes are plain `.md` files in `/mnt/onboard/sigma-scribe/notes` (shown as `sigma-scribe/notes` on the computer). Leave the app, connect over USB, tap Connect, copy the folder. To keep notes in step with other computers without cables, see [sync.md](../10-wifi-and-sync/sync-with-syncthing.md).

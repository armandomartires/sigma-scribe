# Files and folders

Your notes are plain `.md` files in `sigma-scribe/notes` on the Kobo drive, so a computer can read them over USB (or by [Sync](../10-wifi-and-sync/sync-with-syncthing.md)).

The folder button opens **Files**: your notes and folders. New note, New folder, a note's More (Rename, Move, Delete), and the **Trash**, where a deleted note waits until you restore it or empty the Trash.

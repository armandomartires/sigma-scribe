# Settings overview

The cog opens Settings: Writing (font, size, margins), Display (Paper or Night, UI scale, drawer, backlight and warmth, orientation), Keyboard & input (keyboard, layout, handwriting), Language, USB & devices, Experimental features, Plugins, Logging, Sync, Journal (folder layout, week start, UTC offset) and Help & about.

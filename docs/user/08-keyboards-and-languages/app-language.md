# App language

By default Σscribe uses the language the Kobo is set to. To choose another:

1. Open Settings → **Language**.
2. Turn **Override system language** On.
3. Under **Interface language**, pick one.

The choice is kept. Turn Override off to follow the Kobo again; **Interface language** is then greyed, with the note "Follows the Kobo's language".

## Languages

English, Français, Português, Deutsch, Español, Italiano, Nederlands, Català, Dansk and Svenska.

## Good to know

- Where a text has no translation, Σscribe shows it in English.
- The translations are machine-drafted and have not all been checked by a native speaker.
- This changes the interface only. Your notes and the keyboard layout are not affected; see [On-screen keyboards and layouts](on-screen-keyboards.md).

# Journal

The journal keeps one note a day. Open a day from the Calendar pane, use a template for new days, and choose how the notes are filed in folders.

## Articles

- [Today's note](todays-note.md): Open or make today's journal note.
- [The Calendar](the-calendar.md): Use the Calendar pane to move between days, months and years.
- [Template](template.md): Start every new day note from your own template.
- [Folder layout and UTC offset](folder-layout-and-utc-offset.md): Choose how journal notes are filed into folders, and set the UTC offset.

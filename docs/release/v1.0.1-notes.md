# Sigma Scribe 1.0.1 for Kobo Forma

A small update to 1.0.0.

## Changes
- **Mouse pointer no longer leaves trails.** The arrow is redrawn in one grey-accurate update, and its path is cleaned up when it hides.
- **Reverse scroll:** Options → Scroll → Traditional or Natural.
- The Options row is now called **USB keyboard & mouse** (it always covered both).

## Install / update
Replace `.adds/sigma-scribe/sigma-scribe` from the package, or copy the whole `.adds/` folder. Your notes and settings are kept.

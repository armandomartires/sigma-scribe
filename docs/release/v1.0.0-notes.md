# Sigma Scribe 1.0.0 for Kobo Forma

A distraction-free Markdown notebook for the Kobo Forma. Write with the on-screen keyboard (or a USB keyboard), read your notes as formatted pages, keep everything as plain `.md` files you can copy over USB.

**Tested on:** Kobo Forma, firmware 4.38.23697. Other models: untested.
**Requires:** NickelMenu (install it first from its own release).

## Highlights
- Editor: Compact and Full on-screen keyboards, landscape keyboards (Split / Full / Centre), touch selection with Cut / Copy / Paste, undo / redo, autosave.
- Library: notes and folders, rename, move, delete.
- Preview: formatted pages (headings, lists, tasks, quotes, code, links), wiki links `[[note]]` that open or create notes, backlinks, and a Graph of your notes — drawn as a map of notes and links (tap to select, tap again to open, drag to pan, − / + to zoom) or as a list.
- Drawer: Contents, To-dos across all notes, Scratch pad. Find & Replace (Ctrl+F).
- Options: Paper / Night, Literata or Atkinson Hyperlegible, Line mode (words per line), size, leading, margin, tabs, keyboard tone, landscape.
- Help: app info and a Markdown reference.
- USB-OTG keyboard (US layout, Ctrl shortcuts) and mouse / touchpad — needs a powered hub or powered OTG cable; experimental, see Help.

## Install
1. Install NickelMenu.
2. Connect the Kobo, unpack `sigma-scribe-1.0.0-kobo.tar.gz` onto the drive's root, eject.
3. NickelMenu → *Sigma Scribe*. Leaving the app saves and restarts into the normal reader.
Update: unpack over the old version — notes are kept. Uninstall: delete `.adds/sigma-scribe` and `.adds/nm/sigma-scribe`.

## Known limits
- Only the Forma is tested. USB keyboard/mouse support depends on the Kobo's USB host mode and a powered hub; while it is on, the Kobo cannot connect to a computer.
- Leaving the app reboots the Kobo (≈ the same as leaving KOReader with a restart).

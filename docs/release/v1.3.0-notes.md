# Sigma Scribe 1.3.0 for Kobo Forma

## Changes
- **Keyboard layouts:** Options → Layout — US, UK, French AZERTY, German QWERTZ, Spanish, Portuguese, Italian — for the on-screen keyboard and USB keyboards.
- **Accents:** dead keys (` ´ ^ ~ ¨) make ê, ñ, ü and friends; Alt (AltGr on USB) gives €, @ and brackets.
- **Shortcuts** keep their letter on every layout (Ctrl+Z is always Z).

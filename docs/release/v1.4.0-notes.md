# Sigma Scribe 1.4.0 for Kobo Forma — first stable release

## Changes
- **Your language:** the interface is in English, French or Portuguese, following the language set on the Kobo. Sigma Scribe only reads the Kobo's setting; it never changes it.
- **Everything translated:** sheets, buttons, keys, status bar, Help and the Markdown reference. The French and Portuguese texts are machine-drafted (best effort) and need a native review; corrections are welcome in `assets/i18n/`.
- Long hints in Options are shortened instead of overlapping the buttons.

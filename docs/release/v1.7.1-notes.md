# Sigma Scribe 1.7.1 for Kobo Forma

## New
- **Vietnamese typing** (Telex and VNI) on the on-screen keyboard and USB keyboards: Settings → Keyboard & input → Layout.
- **Korean typing** (Dubeolsik): jamo become syllables as you type; Backspace takes back one jamo. Korean needs the optional Korean font pack (`fonts/korean.ttf` beside the app); see docs/font-packs.md.

Includes 1.7.0 (Vietnamese), 1.6.2 (interface in seven more languages), 1.6.1 and 1.6.0 (layouts). Your settings carry over unchanged.

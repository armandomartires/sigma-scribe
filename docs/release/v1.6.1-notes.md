# Sigma Scribe 1.6.1 for Kobo Forma

## New
- **Russian, Ukrainian and Greek keyboard layouts**, for the on-screen keyboard and a USB keyboard (Settings → Keyboard & input → Layout).
- On these layouts AltGr gives the Latin (US) keys, so Markdown marks like `#` and `[[links]]` need no layout switch.
- Greek accents: tonos and dialytika dead keys (ά, ϊ…).

Includes 1.6.0 (eleven more Latin layouts), 1.5.5 (language override) and 1.5.4 (handwriting gestures). Your settings carry over unchanged.

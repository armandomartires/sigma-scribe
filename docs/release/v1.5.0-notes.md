# Sigma Scribe 1.5.0 for Kobo Forma

## New
- **Write panel:** tap **Write** in the status bar and draw with a finger or a capacitive stylus. Ink is crisp black and fast; the panel tidies itself a moment after you lift.
- **Undo**, **Clear**, **Cancel** and **Insert**. Insert puts the drawing into your note as an image (an SVG file next to the note, plus the raw strokes for handwriting recognition later).
- Settings → Keyboard & input → Handwriting: pen width (Finger / Stylus) and an experimental **Fast ink (A2)** option, off by default.

## Known limits
- The preview shows inserted ink as "[image: ink]" for now.
- Renaming a note does not move its ink files yet.
- No handwriting recognition yet (next: 1.5.1, character boxes).

Includes 1.4.3–1.4.6. Your settings carry over unchanged.

# Σscribe 1.4.2 for Kobo Forma

## Changes
- **Settings like the Kobo's:** Aa opens Settings with Writing, Display, Keyboard & input, Language, USB & devices and Help & about. Each opens its own page, with checkboxes, inline buttons, steppers and choice lists. Back with the arrow or Esc.
- **Your settings carry over** from 1.4.0 / 1.4.1 unchanged.
- **Scroll bar:** a thin bar on the right edge of the page shows where you are in a note.

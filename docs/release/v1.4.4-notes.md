# Sigma Scribe 1.4.4 for Kobo Forma

## Changes
- **Keyboard size, simpler:** Settings → Keyboard & input now shows an *Auto keyboard size* checkbox (on by default) and a slider with 100%, 125% and 150%. Tap or drag the slider; it snaps to the nearest size. With a USB keyboard, Left / Right move it after you tap it.
- While Auto is on the slider is greyed out (dotted) and shows the size Auto picked; turn Auto off to choose your own.
- Includes 1.4.3: the keyboard no longer grows past 150 % with the UI scale.
- **Your settings carry over** unchanged.

# Sigma Scribe 1.4.3 for Kobo Forma

## Changes
- **Keyboard size:** the on-screen keyboard no longer grows with the UI scale beyond 150 %. Settings → Keyboard & input → Keyboard size: Auto (default; follows the UI scale up to 150 %), 100%, 125% or 150%.
- Keys stay at least 44 px and the keyboard fits in portrait and landscape at every UI scale and language.
- **Your settings carry over** from 1.4.x; the new setting starts at Auto.

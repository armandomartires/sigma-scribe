# Sigma Scribe 1.6.0 for Kobo Forma

## New
- **Eleven more keyboard layouts:** US International, Belgian AZERTY, Danish, Norwegian, Swedish / Finnish, Polish (programmer), Czech QWERTZ, Romanian, Turkish Q, Spanish (Latin America) and Portuguese (Brazil). Pick one in Settings → Keyboard & input → Layout; it applies to the on-screen keyboard and to a USB keyboard.
- Shift + AltGr types capitals such as Ą and Ł; new dead keys for ˇ (š, č, ř…) and ° (å, ů).

Includes 1.5.5 (language override) and 1.5.4 (handwriting gestures). Your settings carry over unchanged.

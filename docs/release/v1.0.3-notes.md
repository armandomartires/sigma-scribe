# Σscribe 1.0.3 for Kobo Forma

## Changes
- **Pointer lag fixed:** the USB mouse / touchpad pointer moves with the fast e-ink waveform and never holds up typing; when it hides, one clean pass removes any trails.
- **Drawer in preview:** Contents, To-dos and Scratch stay open in preview. Tap a heading to jump to its page, tick a to-do (saved at once), or keep writing in the Scratch pad; the note itself stays read-only.

## Context

The platform seam (Phase 2) is for any second target. Phase 3 picks one to pilot: another e-ink device (PocketBook / Kindle / reMarkable) or a WASM web preview of `sigma-render`.

## Decision

Armando deferred this decision to Phase 3. No target has been chosen yet.

## Consequences

No second-target shell is implemented under this record. A written mini-plan and an explicit choice (D6) are required before P3-06 work starts. Device hardware tests stay under the standing emulator-only order unless Armando approves a device pass.

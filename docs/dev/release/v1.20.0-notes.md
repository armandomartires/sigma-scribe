# Σscribe 1.20.0 for Kobo Forma

Since 1.19.1 (`docs/dev/release/v1.19.1-notes.md`).

## Wiki-link autocomplete
- Type `[[` and a bar of note names shows above the keyboard, the notes you opened last first. Each letter narrows it, ignoring case and accents. Tap a name to finish the link.
- Type `#` after a name to pick one of that note's headings instead.
- On a USB keyboard, Left and Right choose, Enter or Tab picks, Esc closes the bar. Undo takes a pick back.

## Fixes
- The Japanese and Chinese candidate chips are now at least the minimum touch size.
- A plugin can no longer ask for a huge shape, and a runaway plugin stops in seconds instead of minutes.
- A case-only rename never overwrites another note; a failed Wi-Fi re-key keeps the saved key; a tap outside the Wi-Fi password field cancels it.
- Renaming a note and the to-do list read inline code and fences the same way the preview does.
- In All notes, the greyed Replace field says why ("This note only"). The `search:` log line is right when the hit cap stops the scan.

# Σscribe 1.21.1 for Kobo Forma

Since 1.20.0 (`docs/dev/release/v1.20.0-notes.md`); 1.21.0 was not released on its own, so this release carries it.

## Replace in all notes
- In the Find bar's All notes scope, All now opens a review sheet: every note that would change, with the old text struck out and the new text in bold. Tick a whole note or single lines; matches inside a `[[wiki link]]` start unticked so a rename never breaks a link by accident.
- A status line under the header counts the link matches left unticked and says how to include them; the **link** tag sits next to the line number. A note whose matches are all inside links can be ticked from its row.
- Replace in N notes applies the ticked matches. Cancel brings the results back.
- A band says what was replaced and offers Undo; the Find bar keeps Undo last replace, also after a restart.
- Safe by design: every original is copied to `.trash/` first, and each note is written through a temporary file and renamed, so a power loss never leaves half a note. The open note is replaced in its buffer as one Ctrl+Z step.
- Apply and Undo write their time to the log. On the Forma, a replace across a 303-note library took under 2 seconds.

## Fixes
- The USB keyboard help page now names the current path, Settings → USB & devices → USB keyboard & mouse, in every language.

# Σscribe 1.19.1 for Kobo Forma

A patch on 1.19.0 (`docs/dev/release/v1.19.0-notes.md` has everything since 1.15.0).

## Search timing in the log
- With Settings → Logging on, each answered search writes one `search:` line: query length, notes read, hits, whether capped, and the time in ms. The query itself is never logged. This is how the search time on the Forma is measured for `docs/dev/perf.md`.

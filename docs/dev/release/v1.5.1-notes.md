# Σscribe 1.5.1 for Kobo Forma

## Fixes
- **Ink shows in preview:** drawings you insert from the Write panel now appear in preview, crisp black (white in Night).
- **Renaming or moving a note keeps its drawings:** the ink files move with the note and its links are updated.
- The strokes file now records the touch contact size when the panel reports it (for handwriting recognition later).

Includes 1.5.0 (Write panel) and 1.4.3–1.4.6. Your settings carry over unchanged.

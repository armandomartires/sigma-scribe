# S2.6 — Touch selection (Android style)

**Release:** v0.2.2 · **Estimate:** 2–3 d · **Depends on:** S2.5 (v0.2.1) · **Branch:** `feat/v0.2.2-touch-selection`

## Goal
Select, cut, copy and paste with the finger alone, as on Android, without e-ink ghosting storms.

## Scope
- Gesture recognizer in core (`sigma_core::gesture`): press / tap / double-tap / long-press (500 ms, 30 px slop) / drag / release, with timestamps; drag updates throttled to one per 150 ms, the lift position always applied
- Device layer: `Event::Touch { Down | Move | Up, x, y, t }` + `Event::Tick` (50 ms) from FBInk/evdev (MT protocol B, slot 0 only; lift from tracking id −1, BTN_TOUCH 0, pressure 0 or touch-major 0); the desktop window maps mouse press/hold/drag the same way
- Long-press on a word selects it (letters, digits, `_`, inner `'`/`-`); on whitespace/blank it places the caret with Paste / Select all
- Two handles (dot + stem under each end); dragging snaps per char; the other end stays fixed; ends may cross
- Long-press then slide extends word by word
- Floating action bar (inverted, above the selection or below it near the top): Cut, Copy, Paste, Select all — internal clipboard and undo shared with the keyboard; hidden while dragging; tapping elsewhere, typing or Esc dismisses it
- Double-tap on text selects a word (double taps on keys still type twice)
- No animation; only changed regions are refreshed (fast waveform)

## Test checklist
### Desktop / simulator
- [x] recognizer: tap, hold with wobble, late hold, drag vs hold, throttling + flush, double-tap rules
- [x] evdev: protocol B slot 0, ignore slot 1, lift variants, move epsilon, timestamps
- [x] render: handles/bar placement and hit targets, offset ↔ point round trip
- [x] app: touch typing unaffected (double taps, holds, sloppy taps on keys); emulator script
### On-device (Kobo Forma)
- [ ] Long-press a word ~½ s selects it; the hold fires reliably without moving the finger
- [ ] Drag end and start handles; selection follows within ~150 ms, no ghost trail beyond a light residue
- [ ] Long-press and slide extends by words
- [ ] Cut / Copy / Paste / Select all; Ctrl+Z undoes a cut or paste
- [ ] Long-press on blank space → Paste
- [ ] Double-tap selects a word; tapping elsewhere dismisses
- [ ] Fast typing on the keyboard is unchanged (no missed or doubled keys)

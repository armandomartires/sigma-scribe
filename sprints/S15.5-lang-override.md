# S15.5 — Override system language (v1.5.5)

Decision 57 (user request after the 1.5.4 device install: with the Kobo set to Portuguese the app's Language row was greyed and could not be changed). It reverses **S14-D2** ("no Options language override"), which the S14 scope had listed as optional (default: Kobo setting). Emulator and CI only (decision 48).

## What
- Settings → Language → Interface: **Override system language** (checkbox, Kobo style, **off by default**) and **Interface language**.
- **Off:** the interface follows the Kobo's `CurrentLocale` (`.kobo/Kobo/Kobo eReader.conf`, read-only, never written, EN fallback; unchanged from v1.4). Interface language shows the system language in the slider's static grey (`slider::MUTED`, 0x88, the S14.5 disabled style) and is not a control (`Kind::Muted`).
- **On:** Interface language is a normal row (value in ink, black on Paper / white on Night) opening a choice page: English, Français, Português (names in their own language, not translated). The choice is applied at once (full refresh, like Paper) and saved.
- Turning the override on **seeds the choice with the language in use**, so nothing changes until a language is picked. Turning it off goes back to the system language and keeps the last choice in the file.
- A different system language does not win while the override is on (also after a restart).

## Settings keys
- `ui_lang_override=on|off` (default `off`), `ui_lang=en|fr|pt` (default `en`; unknown values ignored). Files without them load with the override off, so 1.4.0–1.5.4 behaviour is unchanged; older binaries ignore the keys.

## Translations
FR "Remplacer la langue du système", PT "Substituir o idioma do sistema", plus the hints (machine-drafted, best effort, decision 31).

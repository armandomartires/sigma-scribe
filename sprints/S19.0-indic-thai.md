# S19.0 — Indic scripts and Thai: layouts, shaping, clusters (v1.9.0)

v1.9 wave W3b (plan §12.6, §12.8). Emulator only; not installed, not tagged.

## Scope
- `KeyLayout::{Deva, Bn, Ta, Th}`: InScript tables (Devanagari for Hindi, Marathi, Nepali; Bengali; Tamil) and Thai Kedmanee; AltGr is the US layer; Full board only (`has_compact`).
- Shaping: `is_complex_text` sends Indic, Thai, Lao, Tibetan, Myanmar and Khmer rows through the v1.8 shaper; joiners stay with their neighbours; four faces bundled.
- Clusters: `Buffer` caret, Left / Right and Delete by extended grapheme cluster (`unicode-segmentation`); Backspace by code point (decision 10). `wrap` breaks only on cluster boundaries and applies the Thai rules.
- Key caps show vowel signs on a dotted circle.

## Decisions
- S19.0-D1: one Devanagari InScript layout serves Hindi, Marathi and Nepali (the standard layouts share the key positions).
- S19.0-D2: Tamil is InScript, not Tamil99 (plan); the same positions as Devanagari, Tamil has no aspirates so Shift repeats the base letter there.
- S19.0-D3: digits stay ASCII (Markdown lists); Shift+3..5 carry ृ ः ऋ (and the Bengali and Tamil equivalents).
- S19.0-D4: no dictionary word breaker for Thai yet; rows break between syllables, honouring the leading-vowel and following-sign rules. A segmenter (ICU4X data, ≈0.3 MB) is the follow-up.
- S19.0-D5: the fonts are bundled (542 KB for four), not optional packs, as in v1.8.
- S19.0-D6: Gurmukhi, Gujarati, Telugu, Kannada, Malayalam and Sinhala would follow the same pattern (font + InScript table); not in this release.

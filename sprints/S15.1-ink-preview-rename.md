# S15.1 — Ink in preview, ink follows rename/move, contact size (v1.5.1)

Patch for the 1.5.0 deviations 2 and 3 (decision 51). Emulator and CI only (decision 48); device checks in `docs/device-checklist-prerelease.md`.

## Ink in preview
- `preview::layout_with_images`: a paragraph made only of `.ink/…/*.svg` images draws them, one line each, at x = 0 with a 0.25 em pad. Other images, `..` paths, missing or unparsable files keep `[image: …]`.
- `ink::Raster::from_svg`: resvg 0.45 (runtime dependency of `sigma-render` now; `default-features = false`, no text), 300 ppi so the mm sizes come out at their real size on the Forma, shrunk to the column width, alpha ≥ 128 → ink. 1-bit: drawn **pure black on Paper, pure white on Night**, so DU updates over it stay exact.
- Insert (1.5.0) put the image line directly between text lines, which Markdown joins into one paragraph; it now adds blank lines so the image is its own block. Blocks inserted by 1.5.0 next to text keep showing `[image: ink]` until a blank line is added.

## Rename and move
- `sigma_core::ink::carry(old, new)`, called by `Library::rename` and `Library::move_to` for notes (not folders: a folder's notes keep their `.ink/` inside it). Moves `.ink/<old stem>/` to `.ink/<new stem>/` beside the new path, `-2`, `-3`… if taken, removes an emptied `.ink/`, and rewrites `](.ink/<old stem>/` → `](.ink/<new>/` in the note when the stem changed.
- The app saves the open note before renaming (as before) and takes the rewritten text back into the buffer afterwards (`reload_ink_links`), caret kept.

## Contact size
- `evdev::Decoder` keeps the primary contact's `ABS_MT_TOUCH_MAJOR` per touch and publishes it with each Down / Move (`evdev::contact_major()`, -1 = unknown, cleared on lift).
- Ink points carry `major: Option<u16>`. Strokes file format **version 2**: `"contact":"touch_major"` and `[x,y,t,major]` when any point has it, else `"contact":null` and `[x,y,t]` (emulator, desktop, panels without the axis).

## Tests
- core: `carry_moves_the_folder_and_rewrites_links` (rename, move, taken folder, no ink); strokes JSON with and without contact.
- device: `contact_major_is_kept_per_touch_and_absent_without_it`.
- render: SVG → 1-bit raster at 300 ppi, shrink, bad SVG, blit only ink.
- app: preview draws ink (Paper black, Night white, no placeholder); missing / `..` images keep the placeholder; contact `null` in the emulator; 1.5.0 tests updated for the block insert.
- Emulator: `tests/emu/v1.5.1-ink-preview-rename.script` (insert, preview Paper/Night, rename, move, preview after move). Screenshots `docs/screenshots/v1.5.1/`.

## Deviations
- 1.5.0 ink lines not separated by blank lines still show the placeholder (see above).
- Renaming a note still drops other notes' `[[wiki]]` backlinks to it (existing behaviour, not ink).
- Binary grows by resvg/usvg/tiny-skia at runtime: 3.15 MB (1.5.0) → 4.05 MB (CI build).

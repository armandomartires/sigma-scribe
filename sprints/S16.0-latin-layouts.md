# S16.0 — More Latin keyboard layouts (v1.6.0)

Decision 58. First sub-release of v1.6 wave W1 (plan §12: Latin, Cyrillic, Greek). Emulator and CI only; not installed, not tagged.

## Scope
- New `KeyLayout` variants in `crates/core/src/layouts.rs`, each a base/Shift/AltGr table over the same 48 evdev keys: US International, Belgian AZERTY, Danish, Norwegian, Swedish / Finnish, Polish (programmer), Czech QWERTZ, Romanian, Turkish Q, Spanish (Latin America) and Portuguese (Brazil). Tables follow the xkb basic variants, trimmed to the 48 keys (no ABNT2 `/?` key: `/` and `?` are AltGr+Q/W on Brazil).
- Shift+AltGr on an AltGr letter gives its capital (`char_for_code`, `position_of`, USB typing).
- Dead keys: caron U+030C and ring U+030A added to `is_dead`, `spacing` and `COMPOSE`; acute extended to n s z l r.
- Compact board: Belgian uses AZERTY rows, Czech QWERTZ.
- FR/PT labels for the new layouts.

## Decisions
- S16.0-D1: Nordic, Czech, Turkish AltGr rows are partial (common symbols only; no dead keys on AltGr). Full xkb parity is not a goal.
- S16.0-D2: Indonesian, Malay and Filipino (W1) use US or **US International**; no separate tables.
- S16.0-D3: Catalan uses Spanish; Dutch uses US International (the common Dutch setup); Canadian French deferred.
- S16.0-D4: v1.6.1 = Cyrillic (Russian, Ukrainian) and Greek layouts; UI catalogs for the new languages come later.

- S16.0-D5: the Layout list now spans two pages; the 1.4-sheet names `Layout/+` / `Layout/-` still work for a neighbour on the same page (no wrap across pages).
- S16.0-D6 (CI fix found on the way): the emulator step looped over the scripts without failing on any but the last one; it now stops at the first failing script (`|| exit 1`). All scripts pass with the fix.

## Tests
- `app/tests/layouts.rs`: a USB typing sentence per new layout (dead keys, Shift+AltGr), wrap-around uses the last layout.
- Core layout tests (row lengths, Shift on every key, a–z/0–9 typeable) cover the new tables.
- Emulator: `tests/emu/v1.6.0-latin-layouts.script` (10 shots in `docs/screenshots/v1.6.0/`, incl. the Layout list in landscape).

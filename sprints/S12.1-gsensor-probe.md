# S12.1 — 1.4.6-probe: log-only g-sensor probe

> **Status:** BUILT 2026-10-22 on branch `v1.4.6-probe` (draft PR, **not merged**, not a release). Implements item 1 of the S12 device check list (plan decision 39): a read-only probe of the sensor node and codes.

**What it does:** `crates/device/src/gsensor_probe.rs`, started from `KoboDevice::open` (Kobo build only):
1. Reads `/proc/bus/input/devices`, writes every block with an `MSC` bitmap and the node `gsensor::find_node` picks to `/mnt/onboard/.adds/sigma-scribe/gsensor-probe.log`.
2. Opens that node **read-only, without EVIOCGRAB**, and appends one line per event: `t=…ms type=… code=… value=… guess=…` (guess = what `Tilt::from_msc_raw` would say today).
3. Stops at 2 MB.

**What it does not do:** send events to the app, change rotation, write anything outside that log, touch sysfs. `gsensor::ENABLED` stays `false` (compile-time check in the tests).

**Next (after the log comes back):** map 0x19 / 0x1a to the right landscapes, then decide on `ENABLED = true` in a normal release (separate approval).

## Fix 2026-10-22
The probe now opens **every** input node that reports `MSC_RAW` (gpio-keys can, too), one read-only thread each, and tags each log line with `node=/dev/input/eventN`; the header lists all nodes read.

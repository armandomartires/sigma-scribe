# S2.5 — Full on-screen keyboard

**Release:** v0.2.1 · **Estimate:** 2–3 d · **Depends on:** S2 (v0.2.0) · **Branch:** `feat/v0.2.1-full-keyboard`

## Goal
A second, Windows On-Screen-Keyboard style layout ("Full") next to the brief's Compact board, with modifiers, navigation keys and Ctrl shortcuts, so writing and editing need no USB keyboard.

## Scope
- Full layout, 16-unit grid, five rows (portrait 1440 px):
  `Esc ` 1–0 - = Back` · `Tab q–p [ ] \ Del` · `Caps a–l ; ' Enter PgUp` · `Shift z–/ Shift ↑ PgDn` · `Ctrl Alt Compact Space Home End ← ↓ →`
- Shift one-shot → second tap locks (bar under the label) → third releases; Caps toggles letters only (Shift inverts Caps); Ctrl/Alt one-shot; active modifiers drawn inverted
- Ctrl+A/C/X/V (internal clipboard), Ctrl+Z/Y (undo/redo in core, word-sized steps, 200 cap), Ctrl+←/→ word jump, Ctrl+Home/End document ends; Shift+arrows/Home/End/PgUp/PgDn extend a visible selection
- `Full` key on Compact, `Compact` key on Full; choice saved in `notes/.sigma-settings` and restored; **Full is the default** when nothing is stored (user decision 2026-10-21)
- E-ink: only changed regions are sent to the panel (separate rectangles per changed key cap / text row / status), fast waveform for keys
- Compact board and all v0.1/v0.2 behaviour unchanged (Compact bottom row gains the `Full` key)

## Interaction with S4 (landscape keyboards)
S4's landscape Centre / Split / Full + num/arrow pad reuse this work: the key set, modifier state machine, shortcuts and unit-grid renderer are layout-independent, so S4 adds landscape row tables (Full in landscape = this board plus a separate nav/num pad) and the Options "Keyboard" row replaces the toggle key as the primary switch (the key stays). S8's USB keyboard path should route Ctrl/Shift combos through the same shortcut code.

## Deliverables
- v0.2.1 package; screenshots `docs/screenshots/v0.2.1-*.png`; emulator script `tests/emu/v0.2.1-keyboard.script`

## Definition of done
- Keys ≥ 80 px wide (1-unit) and 66 px tall on 1440×1920; keyboard ≤ 1/4 of the screen; page ≥ 1300 px
- fmt, clippy, tests, emulator scripts, ARMv7 build green; v0.2.1 on-device checklist passed

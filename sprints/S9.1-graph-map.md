# S9.1 — Graph map

**Release:** v1.0.0 (added to the v1.0 scope before release) · **Estimate:** 2–3 d · **Depends on:** S9

## Goal
Draw the Graph as nodes and links (a map), while keeping the S6 list.

## Scope
- Graph sheet opens on **Map**; a Map / List toggle; the list stays as it is.
- Deterministic layout in `sigma-core` (no device deps): seeded force-directed layout, fixed iteration count; same notes and links → same picture. Cached until the link index changes.
- Nodes: labelled boxes with the note name (truncated with "…"); current note highlighted (filled); orphans on a ring around the edge. Links: straight lines with arrowheads where they stay readable. Crisp in 16 grey levels, Night, portrait and landscape.
- Tap a node: selects it and emphasises its neighbours; tap the selected node again (or **Open**) to open it in preview.
- Pan: drag, page buttons. Zoom: − / + buttons, 4 levels. Opens fitted to the whole graph, centred on the current note. Full refresh on open, toggle and zoom; Partial for pan and selection; regions ≥ 16×16.
- Mouse: wheel zooms, drag pans, click selects / opens.
- ~300 notes: measure layout on desktop, estimate the Forma, use the background thread if too slow.
- The scratch pad is never a node.

## Decisions
- **S9.1-D1 — tap selects, a second tap opens.** The request asked for a tap that both opens and selects. A single tap that opened the note would close the map before the emphasised neighbours could be seen, so the first tap selects (neighbours emphasised, partial refresh) and a second tap on the same note — or the **Open** button — opens it in preview. Tapping empty map clears the selection.
- **S9.1-D2 — dense graphs show dots.** When the average spacing is too small for labels (e.g. 300 notes at the fitted zoom), notes are small squares and only the current, selected and neighbouring notes carry labels; zooming in brings labels back.
- **S9.1-D3 — no background thread.** 300 notes lay out in ~22 ms on the desktop (~0.2 s estimated on the Forma), computed only when the notes or links change (cache). See `docs/perf.md`.
- **S9.1-D4 — orphans on an outer ring** (radius 1.0, linked notes inside 0.8), in library order from the top.
- **S9.1-D5 — four zoom levels** (×1, ×1.6, ×2.6, ×4.2 over the fit); page buttons pan vertically by half the map; zooming back to ×1 recentres on the current note. "Fit centred on the current note" means the scale is chosen so the whole graph fits with the current note at the centre, which leaves empty space when the current note is near the edge (e.g. an orphan).

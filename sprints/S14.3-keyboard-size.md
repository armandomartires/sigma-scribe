# S14.3 — v1.4.3: Keyboard size

> **Status:** BUILT 2026-10-22 (v1.4.3, decision 44, not installed, not tagged). User report: with UI scale above 150 % the on-screen keyboard is too big; 125–150 % is fine.

**S14.3-D1 — own keyboard scale.** `EditorScreen` keeps a keyboard scale `k = page scale × Settings::keyboard_scale() / 100`, next to the UI scale `s`. The layout uses it for key height (58 brief px), gaps (6), padding (10) and the landscape Split / Full / Centre bar (44 / 110 / 8); `draw_keys` uses it for key labels, word labels and the arrow glyphs. Everything else (title bar, status bar, sheets, Settings) keeps the UI scale.

**S14.3-D2 — setting.** Settings → Keyboard & input → *Keyboard size*: Auto / 100% / 125% / 150%. It has four values, so it opens a choice page (like Layout and Keyboard tone). Auto, the default, is `min(UI scale, 150 %)`: at 100–150 % UI nothing changes from 1.4.2; at 175 % and 200 % the keyboard stays at the 150 % size. The fixed sizes ignore the UI scale. No 175 % / 200 % keyboard: the user found those too big.

**S14.3-D3 — settings file.** New key `keyboard_size=auto|100|125|150`, written last. Files without it (≤ 1.4.2) load as Auto; bad values fall back to Auto. 1.4.0–1.4.2 skip unknown keys, so rolling back keeps working.

**Targets and fit.** The 44 px minimum at the device scale and the 42 % (portrait) / 45 % (landscape) height caps are unchanged. `app/tests/keyboard_size.rs` checks every keyboard size × UI scale 100–200 % × portrait/landscape × EN / FR / PT / pseudo-long: all touch targets ≥ 44 px and on screen, keys ≥ 44 px tall, keyboard within its cap, page ≥ 500 px; also that the keyboard at 200 % UI (Auto) is exactly the 150 % height, defaults, parsing and round trips. `app/tests/settings_pages.rs` now also checks the Keyboard size choice page in every language and orientation.

**Translations** (machine-drafted, best effort): "Keyboard size" = FR "Taille du clavier", PT "Tamanho do teclado"; the hint "Auto follows UI scale, up to 150%".

**Screenshots** (`docs/screenshots/v1.4.3/`, plus `eink/`): `v1.4.3-before-keyboard-200-{portrait,landscape}` (1.4.2, built from main) and `v1.4.3-keyboard-200-auto-{portrait,landscape}` (1.4.3), the Keyboard & input page and the choice page. Emulator: `tests/emu/v1.4.3-keyboard-size.script`.

**On-device checklist (needs approval to install):**
- [ ] At UI scale 200 % the keyboard is the 150 % size; typing is comfortable.
- [ ] Keyboard size 100 / 125 / 150 change the keyboard at once; Auto follows UI scale below 150 %.
- [ ] Landscape (Split / Full / Centre) fits; keys are easy to hit.
- [ ] Existing settings load as before (Keyboard size shows Auto).

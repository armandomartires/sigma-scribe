This binary statically links:
- FBInk by NiLuJe — GPL-3.0-or-later — https://github.com/NiLuJe/FBInk
  (commit 886f25f1, built with MINIMAL=true IMAGE=true KOBO=true).
  FBInk's own bundled components keep their licences, listed in its source.
- harfrust (MIT, a Rust port of HarfBuzz), unicode-bidi (MIT / Apache-2.0) and
  unicode-segmentation (MIT / Apache-2.0), for Arabic-script, Hebrew, Indic and Thai shaping
  and right-to-left order.
- skrifa and read-fonts (MIT / Apache-2.0, from Google Fonts' fontations), which read the
  fonts, and zeno (MIT / Apache-2.0), which draws their glyphs.
- Their dependencies: font-types, smallvec, bytemuck, bitflags, once_cell (MIT / Apache-2.0),
  foldhash (Zlib), and yoke, zerofrom, stable_deref_trait (Unicode-3.0 / MIT / Apache-2.0).
- wasmi (MIT / Apache-2.0, a WebAssembly interpreter) with its dependencies (wasmi_core,
  wasmi_ir, wasmi_collections, wasmparser, spin, libm), which runs screen plugins such as the
  Graph map in a sandbox. wasmparser: Apache-2.0 WITH LLVM-exception OR Apache-2.0 OR MIT.
- The Rust standard library and musl libc (MIT / Apache-2.0, MIT).

Bundled plugins (plugins/: graph-map, contents-pane, todo-pane, scratch-pane): by
SIGMArecon, AGPL-3.0-only like the app, WebAssembly modules built from the
sigma-scribe-plugins repository (https://github.com/armandomartires/sigma-scribe-plugins)
at the commit named in each plugin's SOURCE.txt.

EUC-JP to UTF-8, otherwise unchanged; source https://github.com/skk-dev/dict). Copyright
the SKK Development Team and contributors (see dict/SKK-JISYO.L-NOTICE.txt); GNU General
Public License version 2 or (at your option) any later version. It is used here under
version 3 of that licence (https://www.gnu.org/licenses/gpl-3.0.txt), the same family as
this program's AGPL-3.0; it is data read at run time, in its own file. Japanese input
(v1.10) also has a small built-in dictionary written for this project (AGPL-3.0-only).

Dictionaries: the pinyin dictionaries dict/pinyin-hans.txt and dict/pinyin-hant.txt, built from
the Rime project's luna-pinyin and essay data (https://github.com/rime/rime-luna-pinyin,
https://github.com/rime/rime-essay), GNU Lesser General Public License version 3 (dict/LGPL-3.0.txt),
with data from Chewing, OpenCC and the Android Pinyin IME (Apache-2.0), CC-CEDICT and MoeDict (CC0);
see dict/PINYIN-NOTICE.txt. Modified (reduced, Simplified form made with OpenCC), used as data
read at run time, in its own files. Chinese input (v1.11) also has a small built-in seed written for
this project (AGPL-3.0-only).

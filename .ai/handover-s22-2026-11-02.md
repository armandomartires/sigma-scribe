## The three fixes, with the evidence
1. **`[[note#heading]]`** — `crates/core/src/links.rs:37` `resolve` never strips `#`; `links.rs:88` `rewrite` does. `app/src/nav.rs:79-86` then creates `note#heading.md`. Verified by reading both functions.
2. **Ctrl on non-Latin boards** — `crates/core/src/keyboard.rs:726` lowercases the layout glyph; `full_rows` at `:383` builds `Key::Char` from `self.lang.chars(i).0`; only `crates/device/src/usbkbd.rs:274` uses `KeyLayout::shortcut_char` (`layouts.rs:992`). Verified by grep: no other caller.
3. **Back after rename/delete** — `app/src/files.rs:254-269` (rename), `:423-461` (move, inside `FilesHit::Open` when `f.moving` is set) and `:523-532` (delete) never touch `self.history`; `nav.rs:50` `go_back` opens the popped path; `lib.rs:462` `open` loads without an existence check; `crates/core/src/store.rs:88-92` returns `Ok(None)` for NotFound, which `load_note` (`lib.rs:524`) turns into an empty writable buffer. Verified by reading all four. `reorganise_journal` (`app/src/settings.rs:229-240`) already does the right remap-and-prune for Journal; factor it out. The last note cannot be deleted (`library.rs:592`), so that case needs nothing.

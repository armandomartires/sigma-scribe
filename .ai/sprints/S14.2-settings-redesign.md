# S14.2 — v1.4.2: Kobo-style Settings + scroll position bar

> **Status:** ✅ DONE (passed on the Forma, confirmed 2026-10-27); built 2026-10-22 (v1.4.2, decision 43, not tagged). Proposal: `docs/design/settings-redesign.md` (draft PR #16), approved with: checkboxes like the Kobo; two-way choices kept inline; Aa opens the Settings root; settings migrate.

**Look (reference: a public photo of a Forma's Settings → Developer options page, goodereader.com, used for reference only):**
- Top bar: back arrow left, small centred "Settings" in a serif, X right, no rule under it.
- Large serif page title, with "Page i of n" in italics on the right when a page has several sub-pages.
- Grey section bands with small capitals ("TEXT", "LINE LENGTH" …).
- Rows of about 52 brief px (114 px at 200 % on the Forma), with the serif label and a colon on the left; on the right an italic value, a checkbox with an italic "On", inline buttons or a stepper. 1 px separators inset to the text width, none before a band.

**Structure (S14.2-D1):**

| Category | Sections and rows |
|---|---|
| Writing | Text: Type (inline), Size, Leading, Margin (steppers) · Line length: Line (checkbox), Words per line (stepper) · Tab key: Tab key (inline), Tab width (choice) |
| Display | Page: Paper (inline), UI scale (stepper), Drawer (inline) · Orientation: Orientation (choice; Auto shows its status), Upside down (checkbox) |
| Keyboard & input | Keyboard (inline), Layout (choice, 7), Keyboard tone (choice) |
| Language | Interface language (read-only; follows the Kobo) |
| USB & devices | USB keyboard & mouse (checkbox), Scroll (inline) |
| Help & about | App info, Markdown reference, USB help (open the Help page) |

**Interaction (S14.2-D2):**
- Tap a category to open it, a choice row to open its list, and a choice to pick it (saved at once, then back).
- The back arrow or Esc goes up one level; Esc on the root closes Settings, and X closes from any page.
- The page buttons turn sub-pages, as does a tap on "Page i of n".
- Settings always reopen on the root.

**Migration (S14.2-D3):** no format change: `.sigma-settings` keeps its keys, so 1.4.x files load unchanged (`app/tests/settings_pages.rs`).

**Scroll position bar (S14.2-D4, added by the user while this sprint was in progress):**
- A 6 px strip on the page's right edge, inside the margin: a dashed 1 px track and a solid thumb, sized by visible rows over total rows and placed by the scroll position (minimum 24 px).
- Only 0x00 and 0xFF are drawn; on Night pages it inverts. It is DU-safe.
- It is drawn into the frame and so only reaches the panel through the frame diff when the scroll changes.
- Hidden when the note fits. Display-only: a tap or drag on a 6 px strip would compete with caret placement at the line ends, so it is not added.

**Deviations from PR #16:**
- There are no chevrons on rows, following the Kobo reference: the value in italics marks a row you can tap.
- Steppers stay as they are.
- Category rows show their summary in italics.
- Section bands were added after the reference.
- "Words per line" is its own row under Line.
- The proposal's "Connected device" row on USB & devices is not built.
- Labels end with ":" in every language, so French has no space before the colon; this is noted for the native review.

**Tests:**
- `crates/render/src/options.rs`: every page fits in both orientations; every old row has a category; the row kinds follow the approval; open, toggle, pick and back.
- `app/tests/settings_pages.rs`: Aa opens the root; back and Esc; Help & about; every page at 200 % in EN, FR, PT and pseudo-long, portrait and landscape; migration.
- `crates/render/src/editor.rs` `scroll_bar_tests`.
- Script `tests/emu/v1.4.2-settings.script`; all older scripts pass unchanged.

**Device check:**
- Settings legibility and tap accuracy at 200 %, including the checkbox targets.
- Choice lists and Esc / back with a USB keyboard.
- Page buttons on a long page in landscape.
- The scroll bar stays crisp when scrolling with page buttons, the wheel and typing, with no grey residue.

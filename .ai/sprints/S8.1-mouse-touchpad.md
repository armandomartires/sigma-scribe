# S8.1 — Mouse & touchpad

**Release:** v0.8.1 · **Estimate:** 2 d · **Depends on:** S8

## Goal
Use a USB mouse or touchpad (e.g. the touchpad of a Logitech K400 Plus on its Unifying receiver) alongside the USB keyboard: point, click, select and scroll, without hurting the e-ink panel.

## Scope
- Detect evdev relative-pointer devices (`EV_REL` with `REL_X` + `REL_Y`), including the mouse half of a combined keyboard + pointer device. The touch screen (absolute) and the page/power buttons are never pointers.
- On-screen pointer: small arrow sprite, outlined so it shows on Paper and Night; partial (Fast) refreshes only, regions ≥ 16×16; redraws throttled to ~150 ms; hidden after 3 s without movement and as soon as a key is typed.
- Left click = a tap everywhere (caret placement, every button, rows, sheets).
- Left drag on the note = select text (the same buffer selection and selection bar as touch).
- Double-click on the note = select the word (the touch double-tap path).
- Right / middle click and long-press: nothing new (decision S8.1-D3).
- Wheel (and touchpad two-finger scroll when the receiver sends `REL_WHEEL`): note = caret and view move 3 rows per notch; preview, Files, Graph and Help = one page per notch.
- Unplug safe; pointer needs the same host mode as the keyboard (Options → USB keyboard On).

## Decisions
- S8.1-D1: the pointer uses the same host-mode switch as the keyboard (Options → USB keyboard On); no separate setting.
- S8.1-D2: wheel in the note moves the caret 3 rows per notch (the view follows; there is no caret-free scroll in the editor); one page per wheel event elsewhere.
- S8.1-D3: right/middle click and long-press do nothing new; selection handles are not draggable with the mouse (drag a new selection instead).
- S8.1-D4: the pointer also hides on any touch or tap; motion is raw counts, no acceleration.
- S8.1-D5: click acts on release at the press point (a tap), so a press-move-release outside the note is still a tap where it started.

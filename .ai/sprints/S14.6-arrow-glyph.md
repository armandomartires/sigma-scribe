# S14.6 — v1.4.6: back-arrow icon and glyph audit

> **Status:** ✅ DONE (passed on the Forma, confirmed 2026-10-27); built 2026-10-22 (v1.4.6, decision 47, not tagged).

**Bug:** Files inside a folder showed "▯ Up to Files": the crumb was the text "← Up to Files" in Atkinson Hyperlegible, which has no U+2190, so fontdue drew glyph 0 (an empty box). Help's "← Back to Help" had the same problem.

**S14.6-D1 — icon, not glyph.** `icons::draw_back_arrow` draws the Lucide `arrow-left` icon (the same resvg-baked mask as the Settings back arrow), about one text height tall, where the "←" was; the label follows. Used by the Files crumb and Help's "Back to Help". The tap targets are unchanged.

**S14.6-D2 — audit and fallback.** Audit of every catalog string (EN keys, FR and PT values, the pseudo-long locale) and every non-ASCII character in string literals of `crates/render`, `crates/core` and `app` against Literata, Literata SemiBold, Literata Italic, Atkinson and Atkinson Bold. Found missing in both Atkinson faces: ← → ↑ ↓ (U+2190–2193): Graph list details ("→ chapter-01 · ← chapter-01"), the USB hint in Help → App info ("See Help → …"), and the keyboard's arrow labels where they are drawn as text. ↔ and ⇄ appear only in comments. Nothing else was missing (all accented FR/PT letters, · … — are covered). Fix: `Fonts::face_for` picks, per character, the requested face if it has the glyph, else the first bundled face that does (Literata has the arrows); `width` and `draw` use it, so measuring and drawing agree. `Fonts::has_glyph` and `Fonts::missing` support the test.

**Test:** `app/tests/glyphs.rs` fails when any catalog string (any language) or UI literal has a character that no bundled face can draw; it also checks that the 1.4.5 case (Atkinson + "←") is detected and resolved, and that an unknown character (U+E000) is reported.

**Screenshots** (`docs/screenshots/v1.4.6/` + `eink/`): before (1.4.5, built from main) and after for the Files crumb, Help → App info ("Back to Help") and the Graph list. Emulator: `tests/emu/v1.4.6-arrow-glyph.script`.

**On-device checklist (needs approval to install):** the Files crumb arrow and the Help back arrow look right at 200 %; Graph list arrows are legible.
